# 🧼 Lonetex — Smart Inventory & Warehouse Management System

An enterprise-grade SaaS inventory management dashboard tailored specifically for **Lonetex** cleaning products and textile manufacturing. Tracks dynamic SKU variations, multi-location stock dispatches, physical rack allocations, and inventory valuations in real time.

---

## ⚡ Key Capabilities

* **📦 Product Catalog & Dynamic SKUs**
  * Detailed categorization across Kentucky Mops (Loop-End, Cut-End, Polyester), Flat Microfibers, and Hardware Handles.
  * Real-time search, category filtering, and instant image preview modals.
  * Direct CSV export and in-app product management.

* **🔄 Stock Movement & Audit Ledger**
  * Complete transaction tracking: **Stock In** (factory batches), **Stock Out** (dispatches/sales), and **Stock Adjustments** (audit reconciliation & damages).
  * Automated real-time balance calculations with instantaneous UI sync.

* **🏭 Multi-Facility Rack Management**
  * Real-time visibility across **Lahore Factory (LHR-FAC)**, **Lahore HQ (LHR-HQ)**, and **International Hub (KSA-HUB)**.
  * Shelf & Bin ID mapping (e.g., `A-01-A`, `A-02-B`) for physical location tracking.
  * Live facility-level wholesale valuation and capacity monitoring.

* **🎨 Modern SaaS Interface**
  * Built on an enterprise dark slate theme with responsive Light/Dark mode toggling.
  * Glassmorphic metric cards, glowing status pills, and sticky table navigation.

---

## 🛠️ Tech Stack

* **Frontend:** React 18
* **Tooling:** Vite
* **Styling:** Tailwind CSS (Custom enterprise theme & glassmorphism)
* **Icons:** Lucide React
* **Data Layer:** LocalStorage state synchronization with schema migration support
